# NavLab colorful warehouse UI upgrade

This package changes the frontend only. It does not alter the backend, API requests, simulation behavior, or data contracts.

## Included visual improvements

- Detailed 3D autonomous mobile robot with lidar, sensor lights, wheels, safety bumper, and animated status beacon.
- Rich warehouse environment with stocked racking, product cartons, pallet obstacles, safety markers, floor lanes, and colored lighting.
- Brighter, more colorful mission-control interface with a deep-blue dashboard palette, cyan route guidance, and high-contrast controls.

## Apply it

Replace the `frontend` directory in your original `FINAL_PROJECT` folder with this `frontend` directory, then run the project exactly as before. The API calls in `src/api.ts` are unchanged, so it remains compatible with the existing backend.
